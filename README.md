# Bruna Pessoa — Portfolio

Personal portfolio built with React, focused on clean code, responsive design, and good user experience.

🔗 [brunapessoa.github.io](https://brunapessoa.github.io)

## Tech Stack

- React + TypeScript
- Tailwind CSS
- React Router
- Vite

## Features

- Three language support: Portuguese, English, and Dutch
- Light and dark theme
- Responsive design
- Process pages for each project

## Running locally

```bash
npm install
npm run dev
```
